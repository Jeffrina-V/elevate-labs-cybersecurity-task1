# Cyber Security Internship – Task 1  
## Understanding Cyber Security Basics & Attack Surface

This repository contains **Task 1** completed as part of the **Cyber Security Internship at Elevate Labs**.  
The objective of this task is to understand **basic cyber security concepts**, common **attackers**, **attack surfaces**, and awareness of **OWASP Top 10 vulnerabilities**.



## Task Overview

The task focuses on building a strong foundation in cyber security by exploring:
- The **CIA Triad** (Confidentiality, Integrity, Availability)
- Different **types of cyber attackers**
- Common **attack surfaces** in applications and networks
- Importance of **OWASP Top 10**
- **Data flow** in applications and identification of attack points



## Concepts Covered

- Cyber Security Fundamentals  
- CIA Triad  
- Types of Cyber Attackers  
- Attack Surfaces (Web, Mobile, API, Network, Cloud)  
- OWASP Top 10 (Overview)  
- Daily-used Application Attack Mapping  
- Data Flow: User → Application → Server → Database  
- Possible Attack Points in Each Stage
